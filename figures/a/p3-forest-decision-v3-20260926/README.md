# 问题三：树状分支排序与完整候选评价

## 建议图注

图 X　树状分支的内部结果排序及完整方案的评价决策。仅当计算图含至少两棵互不交错的归约树、有汇合操作，且每个操作只有一个已知大小的输出、非根输出只供其唯一父操作使用时，才构造该树方案。对同一父操作的子树，按 `h_i-r_i` 递减处理；`h_i` 是子树计算期间内部输出张量的峰值占用量，`r_i` 是子树完成后须保留的输出量，单位均为字节。该次序最小化**每棵树内部结果**在这种非交错执行模型下的峰值占用，不保证官方内存容量、搬运次数、缓存命中率或完成时间的最优性。树方案保持固定的分核归属。基础方案、共享输入或注意力候选与树方案共用最多三次在线 E0 评价；图中的 E0 指官方评价器，Makespan 指其模拟得到的完成时间（时钟周期）。只有官方 E0 给出的 Makespan 严格小于当前最优方案，才替换当前方案。
