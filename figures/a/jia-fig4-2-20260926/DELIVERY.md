## 图注（草稿）

图 4-2 以一个含分叉、并行链与汇合的最小结构示例展示分叉-归约图的阶段划分与分核。(a) 原始 DAG：源点 s 经分叉点 a 展开三条并行链（链1 b1→c1→d1、链2 b2→d2、链3 b3→c3→d3），在归约点 r 汇合后到汇点 t。(b) 按式 (4-11) 计算分叉阶段 ρ（跨分叉点的边阶段严格递增，汇合不增加阶段）：s、a 属阶段 0；三条链为阶段 1 内保留不切的完整链前沿；剩余归约部分 {r, t} 合并为归约尾 Task。(c) 将阶段按递增次序投影到 K=3 个核心：Core 0 执行 Task 0 (s→a) 后执行 Task 1 (链1)；Core 1 执行 Task 2 (链2) 与 Task 4 (归约尾)；Core 2 执行 Task 3 (链3)。同核 Task 以实线给出顺序；跨核数据依赖（d1→r、d3→r 及阶段 0 到另两核的启动依赖）经 Task 门控与 DDR 中转完成。本图为结构示例，Task 条块宽度无时间含义，不声称实测加速或零 spill。
