Agent interface / v1

与网页共用同一份追加式成绩库。HTTP 只读；无工具执行、求解或评价副作用。

发现与查询

GET /api/v1/health
GET /api/v1/catalog
GET /api/v1/schema
GET /api/v1/cells?problem=P1&case_id=002&cores=4
GET /api/v1/cells?algorithm=q1-bounded-search&run=RUN_ID
GET /api/v1/records?problem=P1&case_id=002&cores=4&offset=0&limit=100
GET /api/v1/records/RECORD_SHA256
GET /api/v1/events?after=0&wait=20
GET /api/v1/blobs/ARTIFACT_SHA256

events.next_cursor 可持久保存，下次从该位置继续；记录 id 是内容哈希，批次重复导入幂等。records 分页返回 next_offset；保留旧 revision，最高 revision 决定当前尝试状态。

数据含义

cells 默认在兼容冻结条件下选 Makespan 最小的 eligible 成功记录；其他指标跟随该方案。最优组合是跨历史方案的档案，不是单一算法实验。eligible 代表原件/身份自动核对，不能代签运行真实性、独立复跑或算法终验。使用 algorithm/run 筛选查看具体实验。

E2 被排除。E1 必须在队长校准表中明确问题、用例、核数、配置和 runtime 范围。include_reported=true 仅用于待核预览，不能替换已有正式记录。缺失为 null，不是 0。

接收流程

成员在原结果目录发布 board-feed-唯一快照.json，并保留其引用的 plan / result / run 原件。队长登记允许的分支；服务每 120 秒检查固定提交并导入，网页每 5 秒更新。远端不提供队长 localhost 写入接口，也不分享登录凭据。

完整 schema 与可复制示例见 /api/v1/schema、项目 docs/benchmarks/BENCHMARK_BOARD.md。目录、提交、哈希、公式、拒收原因与来源均可在单条记录中读取。
