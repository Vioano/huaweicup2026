# 两个预注册实验建议（本轮均未执行）

## 实验一：新生成结构族的正负机制对

固定官方config，不改变bandwidth/capacity/waits。

正例：N=9、K=5；每组件8个沿spine串接的M，每个M之后接一个V(10cycle)。八个共同输入分别4096,4096,65536,65536,65536,65536,4096,4096 B；对应M周期为900,900,100,100,100,100,900,900。private activation全256B。最后可添加ADD(10cycle)，另读第一段V输出作为前向残差，输出仍256B。所有原外部输入采用DDR→COPY_IN→L1，每个共享tensor原图只搬一次，每组件最终一个COPY_OUT。不给不同组件伪造原数据依赖。比较本次输入上冻结v4与唯一带聚合构造。

负例：N=2、K=2；每组件3个串接M，各1cycle，共同输入60,120,60 B，private activation60B，标准边界COPY。中间输入的局部聚合代理有正差，但两次跨核等待远大于计算和节省的服务。应被固定门控启动筛选拒绝，或最终守卫回退。这个拒绝是工程筛选，不声称所有未选切口都被最优性证明排除。

构造规则及阈值先冻结，不依据结果修改。至多2个输入，每个至多基线+一个不同候选，共最多4次E0；若候选拒绝或字节与基线相同，不重复评分。1worker、每E0 30秒、0重试。核对覆盖/联合DAG、共享复制数、残差COPY、L1证书和最终Makespan；任何静态COPY预测或结构证书与官方结果不一致即停止修复契约，不能当性能结果继续调参。

## 实验二：044一次真正两键候选验证

同本包图SHA、config字节，与保存64624原件比较。只运行本规范产生的一个候选，不生成m=3/4/5的候选组，也不扫聚合带边界。

预注册静态核验值：10Tasks；外围3/3/3/2组件，第5core两个聚合Task；共同输入读1571200B；完整COPY1712000B、extra736544B；总footprint证书应成立且无新增spill。此处不是新实验输出。

最多1次候选构造和1次新E0，0重试、1worker；构造与E0各30秒上限。记录read→plan fsync的完整solver墙钟（所有在线选择亦计入），外部E0另计。观察MTE2/M/V重叠与两次汇聚/分发等待；不能将旧时间线当候选阶段时间。
