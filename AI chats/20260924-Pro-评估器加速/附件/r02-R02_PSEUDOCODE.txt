for predeclared block in study:
    # Block is a small complete comparison on the same graph/k/seed/online budget.
    # A family only receives an applicable exposure when its guard really fires.

    optional = at most 2 reviewed new specs or finite parameter-region representatives

    trials = freeze(required + optional + blinded, proposal sequence, parent revisions)

    # Reserve the monetary/oracle/work budget envelope for the comparison as a unit.
    # Do NOT hold every execution CPU/RAM lease while waiting for other members.
    if cannot reserve complete comparison and final reserve:
        park block as BUDGET_NOT_ADMITTED
        stop or use separately preregistered fixed panel; do not compare half a pair

    register trial IDs before starting
    for trial in trials:
        if guard false:
            record NOT_APPLICABLE_FOR_MECHANISM
            if the frozen deployed policy has a fallback constructor:
                run that constructor under the same total online envelope
                record guard coverage=false and actual fallback mechanism
            else:
                mark missing applicable observation; never invent a bad makespan
        else:
            enqueue run_frozen_solver(trial)

    # Completion can be asynchronous. Learning and parenting cannot.
    while outstanding required trials:
        event = shared_service.next_persisted_event()
        validate graph/problem/config/plan/engine/parent/epoch/representation
        if first observed UNEXPECTED error:
            atomically latch stop-dispatch for its declared failure scope
            cancel definitely queued work; terminate or drain started work
            retain started-unknown charge and lease until disposition is known
            do not automatically retry
        persist outcome, stage costs, censoring, aliases, and late results
        # No child algorithm, arm weight or incumbent update here.

    if block failed or incomplete:
        retain evidence; do not make a quality elimination from failure/missing data
        apply declared serial-prefix versus whole-epoch rollback policy
        continue only if NEW / existing manifest explicitly permits that failure scope

    at block barrier:
        pair only same input units and matched online budgets
        compare official quality separately from CPU/wall/memory
        apply frozen objective and tie-break
        protect stratum specialists, unresolved guards and rare-condition candidates
        promote promising specs; park unpromising specs (not global family extinction)
        retain mechanism witnesses even when two specs produced the same plan

F. 仿射 lag 的输出等价整数区间（新推导，未实现或运行）

Applicable only when:
  assignment/components/prefix integers/IDs/mapping order are fixed;
  lag is a positive integer in a finite declared domain;
  lag only affects sorting by (prefix + component_position*lag, op_id);
  no other selection or duration expression reads lag.

Given one legal lag L:
  compute the full ordered plans, preserving IDs and mapping order
  initialize interval to the declared integer lag domain
  for each adjacent pair a,b in each core's sorted order:
      if op_id[a] < op_id[b]:
          require score_a(lag) <= score_b(lag)
      else:
          require score_a(lag) <= score_b(lag) - 1
      # Integer affine inequality; intersect its exact integer solution with interval.
      intersect using integer floor/ceiling division (no floating roots/midpoints)
  all lags in the intersection induce this same total order
  choose ONE representative for evaluation of the same complete ordered plan
  boundary ties are handled by the ID-dependent strict/non-strict inequality
  optionally propose one integer immediately beyond each interval endpoint
  stop at max_regions; report unvisited lag-domain intervals as uncovered

Properties claimed by deduction only:
  adjacent comparisons suffice for a fixed total order; order-identical plans can share score
  intervals do not imply the best score lies nearby or sampling all intervals is cheap
  after assignment, component order, IDs, graph or coordinate formula changes: recompute
  this is constructor-output equivalence, not real-number DDR equivalence
