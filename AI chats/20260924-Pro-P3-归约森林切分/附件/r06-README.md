# R6: raw-late pilot / shared-input prefix bucket

## Scope
One deterministic transformation of a fixed contiguous-stage pipeline anchor.
The owner of every original compute operation and all stage cuts stay fixed.
Move one job (selected by a Step1 raw-rank predicate) to the front on every core;
on downstream cores merge that job's whole local segment into one subgraph.
The earliest scheduled consumers of all shared inputs now occupy one bucket.
Stable Step1-within-bucket ordering promotes shared COPY_INs, observed earlier
through another job in the raw DFS, ahead of the pilot's activation COPY_INs.
The donor is only an earlier compiler traversal; no extra job or warmup compute
is executed. No COPY or physical start time is submitted.

## Files
- `prefix_bucket.py`: pure transformation from exact pre-Step2 Task snapshots;
  calls no official scheduler/evaluator. Rejects if raw-rank, projection,
  topology, or closed-interval capacity predicates fail.
- `static_probe.py`: fixed-044 read-only diagnostic, not the general solver.
  Uses the mounted official attachment and exact documented cuts. Extracts the
  verified Task/COPY builder prefix, stopping before its scheduling loop, then
  invokes Step1. This extraction is a static source diagnostic, not an unchanged
  full official prepare and not an alternative evaluator.
- `extra_checks.py`: independent compute-FIFO longest paths and gated startup
  arithmetic; no official imports.
- `case044_bucket_candidate.json`: the only original-case proposal in this pack.
  Exactly the two permitted submission fields; not scored.
- `static_certificate.json`: source/graph/plan identities, copy prefix, interval
  peaks, unchanged-owner and compute-bound checks, invocation ledger.
- `tiny_checks.py`, `tiny_certificate.json`: supplied raw-word / bucket arithmetic
  and an exogenous-activation-release model. These are not official scores.

## Guarantees and limitations
- Only the exact raw Task graph and stable bucket behavior are used. Grouping
  changes annotations/ordering, not the owner-dependent unannotated Task graph.
- A common-input-only prefix fits virgin L1/UB capacity and therefore has no
  incoming memory-reuse dependency generated by later readers. It is not
  blocked by activation gates; its COPY service still shares DDR/Cache pools.
- The whole-sequence interval test is required, not merely sum(shared bytes)
  <= L1. It includes activations, outputs, and COPY consumers.
- Prefix loading can delay upstream traffic or formerly overlapped compute,
  and grouping can retime producer-side residual COPY_OUTs. No Makespan or
  CacheGain improvement is claimed.
- A full official prepare/export and execution validation remain unperformed.
  Recommend one candidate prepare, then at most one P3 validation, compared
  against the saved identical anchor. Account separately for the additional
  normal prepare performed internally by a fresh P3 evaluation.
