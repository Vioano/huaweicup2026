# 三张优先研究卡

日期：2026-09-23。三卡都依赖恢复并核对冻结官方材料；本次没有执行 E0。它们是研究任务规范，不是人员分工或验收结论。

## 卡 A｜保留动态资源接口，消去固定计算事件

**假说与价值。** 编译后有相当数量的 M/V 固定计算事件，但它们与 COPY、门控、缓存的接口远小于内部节点数。消元使一次候选的内部评分更便宜，并允许对具有相同边界行为的编译结果去重。

**数学依据。** `RESEARCH_MEMO.md` §2 的有限 DAG max-plus 消元命题。相同 H 只有在接口绑定、资源动作、ID/tie 规则等均相同时才构成评分等价。

**先决守卫。** 读取 Step3 与三个运行循环，明确受阻队首是否允许越过；审计固定计算是否只有显式完成依赖；把所有 pool start/finish、cache query/insert、Task 门控保留。任何未解释的动态副作用都把该事件留在边界。

**最小原型。** 不改官方编译，读取准备好的执行图；CSR 拓扑扫描生成稀疏 H；固定 plan 上与 E0 比较保留事件；初版只内部评分，不伪造 full JSON。

**实验。** 计算链、M/V 菱形、内存复用、受阻队首、同刻 cache 事件和高扇出接口。固定相同候选池，消融无消元、只 hash 去重、消元+去重。记录被删事件比例、H 填充、准备成本、独特 IR 数、B=1/16/64/256 新候选成本及最终 E0 最好值。

**停止条件。** 任一保留事件不一致则收紧守卫；接口填充或重编译使端到端成本不降则停用。不能仅凭候选重复的缓存命中宣称高吞吐。

**交付。** 代码/规则守卫、差分报告、触发反例、每次压缩的尺寸与成本、完整接口支持范围。当前：数学检查通过；官方验证未开始。

## 卡 B｜合法分区语法与闭合 Task 分段

**假说与价值。** Q1 的单核串行 Task 在固定边界下有上下文独立的精确时长，允许把选定拓扑词上的指数切分变成 min-plus 最短路；该语法也能给一般多核生成更高可行率的候选。

**数学依据。** `RESEARCH_MEMO.md` §3 的分块拓扑词命题、单集合安全收缩命题、闭合区间 DP。注意各块单独序凸不等于整个商图无环。

**先决守卫。** 同一区间嵌入不同外围分区，核对局部图、生成 ID 的比较关系、Step1/2/3、局部持续时间是否变化。再审计是否有跨 Task 持久状态或额外同步。守卫不成立时只把 DP 当代理，禁止写“原题精确解”。

**最小原型。** 选择少量候选切点、构造稀疏区间 DAG，使用实测准确局部成本；回溯产生 node_to_subgraph 与 core_schedules。限制 M 次局部画像，使 M×画像耗时纳入 5–10 分钟预算。多核扩展仅使用合法 merge/split/core move，加完整展开验证。

**实验。** 短链全切分穷举、双分支汇合、共享输入、跨核往返、局部 ID 上下文变化。区分子族最优与全域最优；测 E0 合法率、最终值、画像次数与编译开销。故障环仅在边来源守卫充分时推广成禁配约束。

**停止条件。** 区间成本上下文依赖即撤销精确性标签；画像过贵则缩小区间集合；语法提高合法率却持续丢掉更好解则增加拓扑词/放宽编辑范围。

**交付。** 精确性适用域、DP 原型、合法输出、E0 子族对照、失败环证书与守卫。当前：数学代价表检查通过；官方局部成本独立性未验证。

## 卡 C｜面向未来 key 的 FIFO 状态商

**假说与价值。** 正式 Q3 的缓存里有很多以后不会再查询或插入的旧键；保留活键顺序、合并死 gap，可以减小快照并让原来不相同的真实缓存状态共享未来评分。

**数学依据。** `RESEARCH_MEMO.md` §4 的右同余命题。规范形：删死前缀；保留活键和大小；合并其余连续死条目的字节。必须把 pending miss insertion 与 logical_tid alias 包含在未来字母表里。

**先决守卫。** 官方缓存只由声明的 query/insert 规则控制未来路径；命中读取发射后是否还会再次查询缓存、同刻 retire/issue 顺序、spill key 映射须源码审计。无法证明死键时宁可保留。

**最小原型。** 用完整官方缓存事件流重放，比较完整 FIFO 与规范形的每次查询和规范后状态；保留 raw 诊断重建路径。之后才嵌入完整评分器。虚拟服务时钟是独立子实验，不混入第一批缓存同余验证。

**实验。** 内部死 gap、死前缀、pending insert、同刻双 miss、容量临界、spill alias、加入第三核争用。错误的 set-only 和 delete-all-dead 摘要须被反例击穿。测 h/真实条目数、快照大小、再会合次数、重放长度、总成本。

**停止条件。** h 基本等于真实条目数，或没有后缀状态再会合，则关闭此优化；任何 hit/miss 不一致即拒绝等价性。不得把规范缓存的 used_bytes/evicted IDs 输出成官方诊断。

**交付。** 未来字母表生成与计数代码、状态商证明、E0 事件级差分、raw 诊断策略、命中守卫统计。当前：199,584 次有限插入穷举、100,000 次随机转移和 5000 次字母表缩小检查通过；Q3 官方端到端未验证。

## 共用计时与发布约束

所有候选的构图、画像、压缩、同步、传输、风险检查和回退计时；冷启动、热路径、完整 CLI 单列。CPU 多核/SIMD 是必选对照，GPU 首先只试相同 H 的整数批量运算；单例端到端不降则不默认开启 GPU。正式最好方案和论文数字始终 E0 复算。E1/E2 规范中的倍率和误差百分比均为目标，不写成当前成绩。
