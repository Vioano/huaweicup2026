## MAP-OBS-01 — 可比较而不污染语义的 L0–L6 观测

- **核心命题**：同一运行环境下，可以以只读观测建立含 provenance 的分层签名，且不改变完整 E0 结果；可以区分 ID 变化、结构变化、时间平移与实际工期变化。
- **branch / commit / 输入**：main `f27ef37bb76dcf556f35d3f2328e405d92241d9c` 的冻结官方原件；Q1 `4dff90ef699fd51845cf482951e8477066f5f566` 的 profile/trace/勘误；Q2 `74c46372faf5910b9b3cce6ad9a61a7e040b17aa` 的 joint；Q3 `a4e7ee13310d693ec4fb5cc236669ceb3b172d1f` 的 pilot。开始前从固定计划中声明最多六个输入，不补入结果好看的新样本。
- **允许修改范围**：新目录 `research/a/coherent_map/MAP-OBS-01/`、对应 tests/results；只读 hook/外层适配器，不修改官方字节。
- **禁止修改范围**：官方源、输入、配置、其他 session 的 src/q1、src/q2、src/q3、生产 E1/E2、已封存结果；不得排序后丢掉未知顺序语义。
- **实验协议**：先写观测 schema、身份与字段来源；逐个无观测/有观测配对，完整对象严格比较；L5 读状态保留更新点，不加新事件；普通计时必须关闭观测。正式图与函数边界合成图分开。
- **输出产物**：observer.py、schema、typed snapshots、原始与 provenance 对齐 diff、未匹配对象清单、观测成本、失败日志。
- **验收指标**：配对全字段零差分；每个生成 COPY/spill 至少能追溯原 tensor/父 Task/锚点；未匹配率如实报告；不把 hash 碰撞等同形式化等价。
- **失败/停止条件**：首次语义差异立即停止该域的精确声明；超过总预算停止，不扩大输入域救指标；对齐不明时保留原始值。
- **依赖**：无新算法依赖；需要可运行冻结 E0 和固定计划。
- **可并行性**：与 MAP-FACT 的静态审读可并行；统一 schema 冻结前不并行修改 schema。
- **预计资源**：1 CPU worker，4 GiB 采样停止阈值（不是硬 RSS 保证）；最多36次完整 E0 调用，45分钟实验窗口；观察/无观察均计数。
- **成功后解锁**：可信的耦合测量、guard 定位、局部模型标签和 D14/D15 比较。

## MAP-FACT-02 — 编译等价边界，而非完整行为商

- **核心命题**：Q1 固定有序 mapping、图、容量、DDR 带宽和 H 时，改变合法归属/核序不改变去掉调度元数据的 L1–L4 编译程序；Q2/Q3 仅在明确的更强相同输入/优先序条件下可复用。
- **branch / commit / 输入**：P1 exact `5bfe53a29c1ba05167239f51ea937e602f7f85b4`；native `03f02e79de4b4bd6f55241385664b154f4332454`；Q1/Q2/Q3 三个固定算法分支；E2 P23 `603b0741e21c449d3db652ebd67c94f2dc014cc9` 只读。
- **允许修改范围**：新研究目录中的编译签名比较与成本实验；不能直接换生产 cache key。
- **禁止修改范围**：不删 generated ID，不把同成员视为同编译；不跨问题借用 scorer；不省略全局事件结算。
- **实验协议**：固定四个父计划，分开测 move/reorder、split/merge、Q2/Q3 priority；各保存 K、调度外壳、统计与完整输出。冷首次准备、8个新调度、变化划分三口径分开。2–5核和末尾空核至少各有一项，未满足入口则标不适用。
- **输出产物**：可复用条件定理/反例、精确 key 字段表、L1–L4 diff、首次/摊销成本、完整对象比较。
- **验收指标**：Q1 声明域零编译差异、全结果 E0 配对一致；性能收益包含键计算/解码/集合恢复/模拟，重复同一计划不当新候选吞吐。是否推广需观察到至少10%端到端节约；阈值为拟议验收值。
- **失败/停止条件**：一个字节/顺序反例即收紧域；真实键检查成本超过被省编译成本则不推进更细缓存；不把失败解释为所有局部性不存在。
- **依赖**：MAP-OBS 的身份与 K-schema；可先独立做静态依赖追踪。
- **可并行性**：按 Q1 与 Q2/Q3 只读分片可并行；生产 evaluator 写权仍归原 owner。
- **预计资源**：单 worker、6 GiB采样停止阈值；最多48次E0和48次固定E1（包括配对/回退），60分钟窗口。
- **成功后解锁**：优先级/归属批次的精确重放，回答何时不需要局部代理。

## MAP-QUOT-03 — 观测商的存活深度

- **核心命题**：非平凡的当前观测类在明确未来 primitive 下能否继续合并；全 result 在逻辑方案上可逆，因此不应浪费资源寻找全 result 大商。
- **branch / commit / 输入**：本报告 `code/quotient_probe.py` 和24份结果先复用；算法输入固定为 Q1 `4dff90e`、Q2 `74c4637`、Q3 `a4e7ee1` 的明确小计划。原题 hash 固定。
- **允许修改范围**：新 `MAP-QUOT-03` 目录中的签名与有限状态划分细化，若生成新输入须单独标 synthetic。
- **禁止修改范围**：不将缺失 continuation 当非法；不凭排序哈希做强去重；不将同 Makespan 类叫同完整行为类。
- **实验协议**：预先冻结 Φ_M、Φ_op-times、Φ_K、Φ_full，操作参数以原 ID 或固定槽位明确；测 h=0,1,2。有限闭域可细化到不动点；非闭合正式邻域只报告有界深度/unknown。操作可用性也进入签名。
- **输出产物**：每层压缩率、可区分最短 continuation、singleton 比例、碰撞和成本、原始计划对。
- **验收指标**：至少一个非平凡 restricted quotient 在 h=2 后κ≥2且构造/检查成本小于省掉评价成本，才考虑用于相应受限域；完整 D15 只在证明或封闭有限域上声明。
- **失败/停止条件**：κ≤1.2 或所有收益只来自 JSON拼写/标签冗余时，停止行为商优化；保留 MAP-FACT，不据此否定编译复用。
- **依赖**：MAP-OBS；只读本轮已有24例即可先启动零E0阶段。
- **可并行性**：可与选择性评估器设计并行，不修改共同 observer。
- **预计资源**：1 worker、4 GiB；新增完整E0最多96次（所有 continuation、配对、重试均计入），60分钟；先零新调用复核本报告有限域。
- **成功后解锁**：经过未来操作检查的候选去重或状态表；失败则明确砍掉通用商假说。

## MAP-STATE-04 — 充分状态的闭合性与字段必要性

- **核心命题**：某个压缩的 plan-state S 同时保留当前观察、primitive适用性，并支持 S(aP)=a_bar(S(P))；仅有“可重放的运行时 checkpoint”不等于 D17。

- **允许修改范围**：新研究目录的状态清单、外部只读快照、字段消融和反例生成；候选表示可试但不接生产。
- **禁止修改范围**：不继承新计划的旧backing；不去掉FIFO顺序、请求身份、release时刻、浮点最后更新时间后仍称精确；不跨评价延续Q3 cache。
- **实验协议**：先声明三个分离目标：Q1固定划分move/reorder的M、Q2固定归属priority的M、Q3相同域的M+cache事件；每删一个状态字段必须给不区分性证明或找同S不同continuation的反例。另单列运行时checkpoint，不混入D17成功计数。

- **失败/停止条件**：必须保留几乎全部原方案+完整程序，或重建成本不降，则停止“紧凑 D17 状态”；可继续数据布局/共享不可变程序但另命名。
- **依赖**：MAP-OBS、MAP-FACT；不依赖全局搜索器。

- **预计资源**：1 worker、4 GiB；最多32次完整E0，60分钟；首先静态证明/反例，禁止为数值漂亮扩大规模。
- **成功后解锁**：可靠的局部更新或严格域缓存；失败能防止错误Markov假设污染代理。

## MAP-SENSE-05 — 耦合与少数敏感方向的实证可否定版本

- **核心命题**：在冻结的操作类分布中，少量操作类是否能在未用于选择类别的图/核数上解释大部分显著响应；是否存在局部编译不变但远端时刻广泛变化。
- **branch / commit / 输入**：Q1 `4dff90e` 的051、044正反例；Q2 `74c4637` 的002/044；Q3 `a4e7ee1` 的008/080。最多四个父图、每个具体plan先锁hash；q/k/操作改变轴逐个声明。
- **允许修改范围**：新实验协议、带provenance的primitive适配和diff汇总；可读取已存E0，复用不计为新增实测。
- **禁止修改范围**：不把resource_word整图替换说成小编辑；不按结果改变操作类定义；不把不连通图距离∞丢掉；不修改原算法默认搜索。
- **实验协议**：预先指定编辑签名、显著时差阈值、均匀操作类权重。每环境平衡采样move/reorder/split/merge等适用类；报告所有无响应/失败。用一组图选前r类，另一组图/核数检验能量覆盖及改善率；比较绝对平移与持续时间变化，区分post-hoc coupling与便宜预测器。
- **输出产物**：J稀疏表、C_layer/C_object/C_distance、guard跨越、类别平衡响应能量、bootstrap按图分组的区间、最强反例。
- **验收指标**：试验性稀疏目标为不超过四分之一操作类解释至少80%保留集响应能量，且显著事件覆盖不只来自一个峰值；这些是预设目标，不是已获定律。
- **失败/停止条件**：需接近全部操作类才覆盖变化、跨图排名不稳定或响应主要由大编辑构成，则删除“少数稳定敏感方向”表述；保留具体宏机制。
- **依赖**：MAP-OBS；primitive适用域由各算法现有代码和局部证明提供，不等待完备性研究。
- **可并行性**：冻结父计划的不同case可并行；共享宿主机资源上限内运行。
- **预计资源**：1–2 CPU worker显式总额、6 GiB采样停止阈值；最多120次完整E0等价标签调用（含父计划/回退/最终确认），90分钟；未完成预设覆盖则报告不足。
- **成功后解锁**：低成本guard候选与macro优先级；失败会砍掉全局稀疏模型。

## MAP-LOCAL-06 — 有拒答的Δ/排序器是否值得存在

- **核心命题**：计入detector、特征提取、拒答和fallback后，局部评估器相对真实E1/native路径能降低达到同质量的时间，而不是只提高离线预测准确率。
- **branch / commit / 输入**：P1 exact `5bfe53a`、native `03f02e79`、E2 P23 `603b0741`；routing审读 `abdfd31`；使用MAP-SENSE冻结成对标签，父计划与q不混淆。
- **允许修改范围**：新研究路由包装器与至多两个低复杂度局部预测器（例如线性/浅树/明确机制公式）；输出实验结果，不接生产默认值。
- **禁止修改范围**：不改backends、不隐藏full/fallback调用、不将native-only开关当0完整评价保障、不用结果后的guard当免费线上特征、不训练大网络。
- **实验协议**：同池比较绝对M、直接Δ、pair ranking、worth-scoring四目标；按图/父计划整组留出。D_r先判断结构域，再估guard风险；模型分歧/域外/宽区间ABSTAIN。保留至少20%精評槽给随机/机制多样挑战者，此比例在试验前冻结。另做exact-only同总预算臂。
- **输出产物**：risk–coverage、top-set保留、shortlist regret、ABSTAIN原因、逐请求route/cost、同预算E0-confirmed质量/同质量时间。
- **验收指标**：试验性门槛：包括所有成本后时间降低≥15%，各固定池遗憾≤1%，不漏预先定义近优集合；必须报告样本量和不确定性，不从小样本零失败声称1%总体错误保证。
- **失败/停止条件**：detector+代理成本不低于精确路径、拒答吞掉收益、模型一致但审计槽发现系统漏优，立即No-Go该专家；不能改用更宽容输出证明成功。
- **依赖**：MAP-OBS、MAP-FACT成本、MAP-SENSE标签；可以先用已存真实池做零新E0回看但不称前瞻。
- **可并行性**：离线拟合与核数延拓可并行；在线策略臂须有相互独立的预算/cache成本口径。
- **预计资源**：CPU 1 worker、4 GiB；新增精评最多64次，60分钟；所有backends自动回退预留最坏1次对应完整评价，E1/E0分别计账。
- **成功后解锁**：Conditional-Go专家路由；失败则保留exact batch+macro，不为框架硬加代理。

## MAP-SCALE-07 — 峰值只是见证：跨k与跨q的映射边界

- **核心命题**：空核嵌入保持有效操作的执行行为（元数据另计）；resource-word类收益可能只在特定q/k/结构guard下保持，不能由k=4一次峰值推出尺度规律。
- **branch / commit / 输入**：Q3 `a4e7ee1` 的case008 exact plan，SHA256 `1935d89ad16a59a52ad62b2e00b4b43f30e783ade40fe481fc6063d905da64ce`；Q2 `74c4637`；Q1 `4dff90e` 的pro008对照；本报告新E0输出先复用。
- **允许修改范围**：新continuation测试适配器、同图同plan的q对照、少量合成结构扰动、独立报告；不自动接最终solver。
- **禁止修改范围**：不把每个k重跑构造器冒称C_k；不改正式config制造成绩；不把Q2/Q3一核重排结果替换B(G)；不假定核心重编号保持同刻事件序。
- **实验协议**：从一个明确k=1计划出发，C_k先在末尾加入空核，再按固定规则迁移原计划的一个既有组；保留父结构与变换谱系。k=1…5逐项评价，同计划q配对。已知peak只作为开发见证；合成扰动一次只改一个图特征。为每个宏给显式S_G/S_q/S_k/S_R和失败预测。
- **输出产物**：嵌入严格投影比较、1–5核延拓路径、guard翻转表、邻近反事实、明确适用域的macro候选或反证。

- **失败/停止条件**：空核嵌入出现未解释差异即停止性能单调性声明；收益迁移失败则收窄S_q/S_k而不覆盖负例；若找不到可预测guard，维持witness，不急称accidental。
- **依赖**：MAP-OBS的对齐；无需等待局部预测器或生成完备性证明。
- **可并行性**：与MAP-LOCAL离线阶段并行；结果供Pro B/最终综合者使用，不代其路由全部任务。
- **预计资源**：1 worker、4 GiB；最多60次完整E0标签（含所有baseline/continuation/q配对/复核），60分钟。
- **成功后解锁**：有条件跨核warm-start与guarded macro；失败会砍掉无条件跨q移植。
