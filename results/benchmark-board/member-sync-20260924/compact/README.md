# 中央紧凑成绩快照（首个接口样例）

固定于current.json的generated_at，包含2855条中央已接收历史及全部来源/准入/指标；gzip为1,084,713字节，解压19,815,519字节，不复制大原件。这个视图表达中央验收结果，不冒充成员本机原件复核。

current.json给出不可变payload_file、压缩SHA256、大小、记录集合与内容hash、序号和发布代码来源。自动传输/签名/升级机制仍在实施；本首包仅以队长实际GitHub评论给出的固定提交为可信交接，不能让任意分支成为中央权威。

生成器为src/benchmark_sync/snapshot.py；6项测试覆盖一致读回、无变化、追加、历史丢失/改写/游标倒退、事件损坏、字节/大小错误及错误路径不建库。生产中央账本只读；0新评分。后续自动发布使用专用小数据通道，固定样例不伪称永久实时快照。
