# Holdout interpreter-path runtime fix (zero scoring)

The first admitted holdout stopped after `006-k5`; it has **not** been retried. Its solver ledger records one E2 request, no native return, an uncertain exception and one possible internal E0 fallback. The recorded command invoked the resolved base Python executable. The original run and its manifest remain historical evidence.

Read-only import diagnosis in `import-only-diagnostic.json` reproduced the cause. Calling the same bytes through `.venv/bin/python` yielded `sys.prefix` at the venv, found `numpy` in that venv, and imported the frozen E2 and official helper modules. Calling `Path(.venv/bin/python).resolve()` yielded the uv base interpreter, `sys.prefix == sys.base_prefix`, no `numpy` spec, and `ModuleNotFoundError: No module named 'numpy'`. The original producer and supervisor had resolved the invocation path before child launch; byte hash verification itself was valid.

The independent holdout runner now preserves the absolute **invocation** path for every child and hashes the resolved real binary separately. Its preflight invokes the selected interpreter to check `sys.executable` equals the invocation path, that a venv is active, and that the frozen E2 and official helper imports resolve under the pinned E2 root. This is import-only and does not construct or score a graph. The supervisor likewise preserves the invocation path and checks the real binary hash. All source, input, gate, RSS, swap, pressure, timeout and stop rules remain intact.

`local-holdout-manifest.json` is a **new** manifest with only `runner_sha256` updated for this fix; `selection-manifest.json`, `singlecore-baseline.json`, and `c665-paired-baseline.json` are byte-for-byte copies of the frozen references so its relative paths remain valid. The old manifest was not edited. The fixed runner's real preflight returned `preflight_ok`, 12 cells, calls 0, source HEAD 15d. The public `results/.../offline-tests.py` was executed after the fix and passed its symlink-path regression, three old saved-cell replays and fake-process supervisor tests; `offline-test-receipt.json` records its hashes. No solver, E0, E1 or E2 call was made during this fix.

Any future dispatch requires a new coordinator admission and gate pins for the new manifest, runner and supervisor. The first stopped attempt cannot be relabeled successful or silently retried.
