## 原件与复核

- `evidence.tar.gz` 保留实际云端归档字节；5 个有效载荷大小和SHA-256由根独立核验。`report.json`、`plan.json`是原字节副本。
- `receipt.json` 是公开收据，省去VM连接输出及本机CLI路径，记录调用/时间/来源/停止回读。Task40/40（含整图20），Fraction4/4，E0/E1/E2/重试均0。探针进程1.32549秒，VM43.42235秒；两者不等于正式统一求解器耗时。已停止VM，独立sessions为空，watchdog已退出。
- 原图864个compute操作，计划恰为两键，20个Task核序无重漏；编译源前后哈希不变，完整重编译签名/流量/整图响应相符。不是新E0验收，也不是全局最优证明。
- `summary.json`为小型诊断索引；`paired-signatures.json`从两份既有报告的signature元组无损转成JSON，包含两方案全部Task/核序，可不重编译就研究响应轨迹。它不是新增模拟，未保存旧原始op ID。重建时按`src/q1/response_oracle.py`的PortOp/Task定义；逐tuple保留work、ddr、need，不能省略MEM。
- `ZERO_CUT_MODEL_BOUND.md`给出限定“不切链、无spill”类的[99264,101836]区间；不是整个P1的界。
