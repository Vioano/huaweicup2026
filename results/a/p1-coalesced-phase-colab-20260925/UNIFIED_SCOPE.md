合并真实 reserve 的 008/K5 候选在 Fraction 模型中为 98932 周期；相同分组、Task ID 和核归属的控制次序为 108668。此前另一整链计划的同模型值为 101836。这三个数不是官方 E0 成绩。当前候选已经固定，独立 E0 仍待执行。

研究入口的 q=7、s=3、body_period=35405 是 008 的已保存参考参数。chain_work=4512 可从当前输入各链计算节点的 cycles 求和，但当前入口仍要求显式注入并逐链核对。它们还不是统一输入驱动的参数选择器。相位、reserve 长度及剩余链分组才是由这些参数和链数计算的。

统一入口必须保留以下边界：

- 从输入验证私人同型链、完整节点覆盖、原始顺序以及均衡分配；不按 case ID 或历史成绩路由。
- 给出由当前图与硬件参数决定的 q、s、period 构造规则、复杂度和停止条件；当前显式参考周期不能当作免费在线输入。
- 重新编译实际 Task 并验证容量、FIFO/依赖、全局 DDR 和完整计划；不能把改变分组后的 Task 沿用旧签名。
- 不适用、失败或无收益时保留原合法方案。模型选优和官方 E0 验收分别记录，在线编译与评分计入求解墙钟。

单个样例的改善不足以履行全量显著提升目标。仅作算术情景：若新官方 E0 恰为 98932，其余 99 图完全不变，以保存的 008 单核基线 487605 和 v4 的 100603 计算，K5 的 100 图平均加速比只增加 `(487605/98932 - 487605/100603)/100 = 0.0008186473865666866`。这不是 E0 预测，也不是新算法的全量结果。不得据此启动或宣布新的全量获胜批次。

用户要求本轮统一算法获得显著提升的完整 Benchmark 并完成同步后暂停。模型门槛、单例 E0 或保存结果的拼接均不触发该完成条件。
