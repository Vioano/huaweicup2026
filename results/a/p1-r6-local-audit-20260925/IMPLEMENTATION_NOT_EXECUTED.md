# R6 branch aid implementation — not executed

`src/q1/branch_aid.py` adds `construct(graph, cores, base_plan) -> (plan, diagnostics)` as a single, deterministic structural candidate. The caller must construct `base_plan` from the same current input before this call. The module has no case-ID, saved-result, timeline, or scorer input. Unsupported shape returns the original plan and an explicit `status=unsupported` reason; successful construction returns `status=candidate-unscored`.

This implementation is **not an accepted algorithm result**. It has not been imported or run against a synthetic or official graph. Task construction, Step1–3 compilation, response simulation, solver, E1, E0 and E2 calls in this segment: **0**. In particular, `task_raw_pipe_lower_bound` is raw compute work only; it does not include COPY, FIFO, MEM, spill, release latency or contention. The caller must add E1/spill and complete Makespan/byte guards in a separately authorized integration step.

The implementation derives Task data-DAG heights from the actual baseline and requires strictly increasing height on each core, at most one old Task per core and height. Each old Task is partitioned into undirected compute components; a wave is eligible only when each component has one sink and its direct compute edges agree with COPY-contracted edges. A single Tarjan bridge pass and block-tree work accumulation per packet selects each donor's highest-scoring two-bridge join. Only the chosen cone is materialized. The code then checks nonempty exact X/Y/J coverage, X predecessor closure, J successor closure, allowed cross-partition edge directions and early external predecessors. Donor/helper roles use the wave's dominant Pipe and are disjoint. All selected donors are placed together by a fixed greedy rule, and a wave is accepted only if its full-batch maximum core/Pipe raw work decreases. The final candidate retains original IDs, checks the Task cap, recomputes static COPY instances/bytes/per-instance ceiling service from original tensors, and verifies the data plus adjacent-core-order DAG with Kahn and the official plan/order validators.

The soft 2-second check is cooperative; it is not a hard kill or a runtime guarantee. The bridge pass and block-tree accumulation are linear in each packet's vertices and edges. Materializing and checking one chosen cone per donor is bounded by O(K(n+m)) per wave with K at most 5 in the official task; packet sorting and greedy placement add O(K²W), with ordinary sort factors, across W waves. Exports are indexed once by `(wave, helper)` for linear schedule emission. The tensor-boundary recount precomputes producer/consumer Task sets, so each tensor's work is linear in its original producer/consumer incidence rather than quadratic in its fan-out. Official COPY contraction and baseline validation are additional work. No repeated per-join whole-graph DFS is used.
