# Packet 惰性展开：纯数学实现与验证

R4 的完整控制器原为伪码；本次实现按下界拆分候选盒、状态改善后重开、未知边保留，以及独立 oracle/展开预算。新 packet 边界利用已审查的 W 先于 P/R 条件，比旧 V 资源项更紧。

固定源码、命令、哈希与 16 项纯测试的覆盖范围见 receipt.json。根代理核对控制器的未处理路径覆盖与标量最优条件，Sol独立审查新 W-first 计算项。

没有运行真实图构造、Task 编译、Fraction 调度响应或官方评分。抽象图最优不表示实际 P1 最优；尚不能报告实际候选编译数减少、求解器提速或新平均成绩。

后续接入须核对同一模型的 gate 记账、真实编译缓存契约、最终完整计划重编译和 E0 验收；未知候选不能按不可行剔除。
