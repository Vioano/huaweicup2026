# 008 的保守容量筛选反例

目的：只检查是否存在被总 tensor 足迹条件排除、却可由冻结官方 Step3 编译为无 spill 执行图的 Task。三个 `(r,q,s)` 在运行前固定为 `(0,2,0)`、`(0,2,2)`、`(1,2,2)`，分别为两条完整链、两条前缀，以及一个旧后缀加两条新前缀。复用严格链族识别、原始 ID 和原投影逻辑。

输入是冻结 `data/raw/a/official-cases.zip` 内 `data/case_008.json`；输入及适配器源码 SHA 在 `receipt.json`，官方源码和配置 SHA 在三份 certificate。运行使用 Python 3.12.13 / macOS arm64，命令为：

```sh
python results/a/p1-memory-response-probe-20260925/probe.py --repo .
```

| r,q,s | UB 总足迹/字节 | 官方 Step3 峰值/字节 | MEM 前驱对 | Step2 spill |
| --- | ---: | ---: | ---: | ---: |
| 0,2,0 | 148228 | 37056 | 3 | 0 |
| 0,2,2 | 148228 | 37058 | 3 | 0 |
| 1,2,2 | 166660 | 55488 | 6 | 0 |

UB 容量为 131072 字节。三者均超过旧总足迹阈值而通过新研究适配器；MEM 前驱逐对存在于 Step3 execution_graph 的 op_preds 及完成前缀条件中。峰值仅为 Step3 编译时证据，未测量有理数回放峰值或真机占用。

本批共 3 次真实图小投影的静态 Task 编译，0 次完整 solver/E0/E1/E2，0 次响应模拟；三次编译和收据写入耗时合计约 0.0070 秒，**不是端到端求解时间**。适配器此前有 6 次极小合成 Task 编译，单独记账。本批无失败、重试、参数扫网格，未生成完整多核提交方案。

结论限于：旧规则是充分性筛选，不能用它排除所有更大分包。仍须证明含内存分配分支的有序同构缓存等价、设计可控的扩展转移域，并对候选做最终完整官方评价。旧有限域 DP 最优结论不因此扩大为新域或全局最优。
