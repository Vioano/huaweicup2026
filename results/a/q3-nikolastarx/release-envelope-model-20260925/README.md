# 多释放输入 FIFO 的完成时间包络

这是对部分预加载模型的扩展：精确处理**给定的**多个外部释放时刻，而不将它们压成一个R。当前0 Task/Step/E0/solver/VM；代码只处理小型整数模型与已保存数据。不是预测E2，不替换官方模拟。有限验证事前固定为 `test_model.py` 的四项、20次直接递推比较；1进程、最长10秒、首异常停、不自动重试。

## 模型和推导

同一输入FIFO共有n笔传输。第i笔固定独占服务为w_i，释放为a_i（普通输入为0，外部激活为一个独立非负变量R_j）。它服务一条串行计算链；总计算为C，读取i首次消费前的计算量为P_i。不同P_i不必与FIFO同序。每笔输入必须有消费者；排除内存回收、内部计算释放和随方案改变的带宽份额。FIFO可与计算并行。

令S_i为前i笔服务和，S_0=0。FIFO完成时刻递推为E_i=max(E_(i-1),a_i)+w_i，因此

`E_i = S_i + max(0, max_(j<=i)(a_j-S_(j-1)))`。

串行计算每到一个输入消费者才等待，其总完成时刻是

`T = C + max(0, max_i(E_i-P_i))`。

设H_j=max_(i>=j)(S_i-P_i)。交换两个最大值后，得到

`T(R) = max(K, max_j(R_j+L_j))`，其中初始 `K=C+max(0,H_1)`，第j笔变量输入的系数为 `L_j=C-S_(j-1)+H_j`；同一释放标签多次出现取其最大系数。最后规范化K=T(0)=max(K,max_j L_j)。一次前缀和与一次后缀最大值扫描即可得到完整函数，O(n)时间与空间。它覆盖首部和中途多个激活，不必采样或猜测释放时刻。

## 对全部释放时刻的比较

同一变量域、规范化后的两个候选A/B满足 `T_A(R)<=T_B(R)` 对所有独立R>=0成立，当且仅当 `K_A<=K_B` 且所有 `L_Aj<=L_Bj`。

充分性是最大值逐项比较。必要性：令全部R=0得到K的条件；再令单个R_j趋于无穷、其余为0，最终该项主导，得到L_j的条件。此判据允许相同函数；严格去重/平手需要另用确定的结构编号。若真实释放时刻相关，本判据仍是保守的充分条件，但不再是其受限可达域上的必要条件。

微例中，全前缀的函数是max(13,R+4)，部分前缀是max(11,R+10)：互不支配。这说明不能仅优化零时刻截距，也不能仅优化对迟到激活的敏感度。两次中途激活的例子在首部释放相同的情况下可从3变102，准确暴露旧单R摘要遗漏的状态。

## 官方应用边界

若把w取官方独占时长，这是一个**固定服务结构代理**；真实共享DDR、Cache状态、整数退休空隙、COPY_OUT竞争和Step3回收会改变w或新增约束。因此不能将本模型支配注册为官方严格剪枝证书，不能据此声称真实M或G改善。先检查真实合桶能产生该FIFO，再保留模型非支配候选，是否评分另按冻结候选和预算决定。多个激活不是唯一遗漏状态，修正它并不等于解决全部官方时序。

`model.py`实现上述签名和比较；`test_model.py`直接按FIFO服务和计算消费事件独立重建，覆盖乱序消费者、同一释放多次出现、无输入、两次激活及全/部分前缀互不支配。所有数值为数学机制，不是赛题成绩。
