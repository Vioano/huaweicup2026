1. 当前五核相对官方单核均值为4.757616679；同计划、同核无L2/只读Cache均值G为1.082917173。两者不可互换。全量求解墙钟均值4.400830秒、P95 20.008882秒是共享四worker实测，不是独占硬件速度。
2. 完整044前缀只使一份机制计划38390→38024（约0.95%），其固定COPY集合的11次重复读已全hit。部分前缀新候选已冻结但未评分，不能虚构收益。无需再问一遍R6/R7。
3. 079分带减少约19.1MB额外COPY却增加90146周期；全量22份已评分同M候选没有更低extra/spill者。只改善复制次数或接受规则不足以自动改善主目标。
4. 十个已识别Cartesian森林在当前五核成绩之上，即使达到忽略通信/容量的计算松弛上界，对100图均值最多增加0.036610526。这是该族的上界，不是可达改进。其机制研究可继续，但不宜作为本轮显著全量突破的首要方向。

## 本轮向Pro提出的数学问题

先判断是否应研究跨多个相邻模块的联合归核和原操作执行词：在共享K/V、逐输入释放、M/V双资源、固定500周期跨核延迟的明确受限族中，给出一个单岛局部最优但联合变化严格更好的可检查家族；然后给出一个规模可控的确定构造和状态界。它必须允许相邻模块共同改变，保留原归约和张量身份，不冻结被本次变换改变的释放时刻；不得把“总工作、总边界字节、一个最大释放时间”误当足够状态。

如果适合前沿DP，需要说明边界状态到底保存哪些tensor/owner/逐端口到达/资源可用性，宽度如何从原图证实，状态如何有界及不能剪掉哪些状态；若复杂度失控，应收缩适用族或给反例，不输出无界搜索作为算法。真实提交仍只有两字段，只有最后一份候选进入独立冻结的小规模官方验证。

目标是发现有价值的新自由度或排除错误路线；不预期Pro保证显著突破。当前读取过的100图全部是开发集，不能重命名为隐藏验证。新机制获得正证据后仍须冻结单一算法并统一全量比较，绝不离线拼赢家。
