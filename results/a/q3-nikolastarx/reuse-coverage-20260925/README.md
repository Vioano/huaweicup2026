# 输入共享构造的结构覆盖

由原始100图的实际张量读者集合识别，10图通过完整二分网格守卫。50个图核坐标中34个能构造降低输入副本覆盖代价的新计划；其中080/5的旧森林入口已用满3次E0预算，其余33格还可增加一次候选。34份方案均与旧最终方案字节不同。0次E0、0次完整solver，约15.6秒单进程结构分析。

这不是新统一算法500格成绩。旧receipt只用于本轮机制实验的预算/计划比较；新入口实际调用数须从新运行验证。所有已识别50格的原图哈希与既有receipt一致。构造耗时是共享主机进程内诊断值，不是冷solver墙钟。

`coordinates.json`保留所有50格（含不支持/预算不足）及计划SHA；`recognition.json`保留100图支持/不支持原因；`summary.json`汇总。只因10图结构适用而纳入机制实验，不按图编号决定算法行为。新运行范围和上限见 `docs/a/q3/REUSE_FAMILY_PROBE.md`。
