097 的完整输入组为 319488+212992=532480 B，单是输入已超过 L1 8192 B；其他九图通过这个必要条件。内部输出前沿按原树顺序模型计算，排除共享输入、COPY 瞬态、地址碎片和实际异步存活范围。**表中“是”不表示已证明可同时常驻，更不证明无 spill。**

该事实排除了在 097 直接采用“两个完整输入组同时常驻”的证明前提；它尚不能解释已观察到的 M 间隙增加，更不说明所有部分输入复用构造都会失败。下一步区分两条证据：既有时间线的精确阻塞边（单独的 2 次 Task/Step3 诊断尚未执行），以及按原始叶/子树交错的部分输入复用构造。
