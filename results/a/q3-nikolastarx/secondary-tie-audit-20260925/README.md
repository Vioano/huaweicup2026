# 次要指标是否仅靠更换平局接受规则就能改善？

答案：现有全量已评分候选没有提供这种现成收益。

只读遍历固定`bff88a66cd76ceb2d75242bf99d34bfe8b1879d4`交付的全部500份森林求解收据，找到22份与最终赢家周期相同、计划不同但未选中的候选。原候选结果和计划此前保存在生产端，已按收据SHA逐一核验并复制到本目录raw，未重跑评价。完整路径和哈希见report.json；audit.py可从保留原生产结果的根目录复现，`--native-root`不含于算法规则。

22份中extra/spill都是0更低、18相等、4更高；字节命中率为2更高、17相等、3更低。两个命中率更高的候选分别是029/K1、081/K1，extra和spill各增加94416B、1144016B，主周期没有下降。没有同方案P2，不能据此推出G改善；命中率的上升也可能包含spill重复读的贡献。

这否定了“只改成M平局时优选较少DDR，就能立即提升本批次指标”的现有证据基础。没有发现已评分且同M、较少额外搬运的候选；不能把它扩写成其他构造不可能产生这种方案。记录中的lower-bound恰好等于最终M而被剪掉的候选数为0，仅针对该批收据的这一条件。

后续优先改候选本身，研究Task级输入复用、跨核边界和内存生命周期的联合结构。不要仅为提高命中率接受更多spill，也不要将22份历史候选离线拼成一个新算法成绩。本轮0新solver/Task/Step/E0/VM。
