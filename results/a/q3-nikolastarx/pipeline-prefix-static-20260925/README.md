## 数学含义与未验证边界

闭区间按每个局部张量的生产者和消费者首次/末次使用计算，在同一步先分配再释放，与冻结 Step2 相符。假设没有初始片上驻留且完整实际 Task 的各存储位置峰值不超容量，按字序执行时无需驱逐，因而 Step2 无 spill。只对共享输入求和不能代替完整 Task 检查。

提前加载还需独立条件：共享输入 COPY 是完整 Task 的开头、只读取未由本 Task 生产的 DDR 输入、没有跨核 release、占用可由初始空闲容量满足。源码复核与本地静态守卫已验证这些条件；**实际 Step3 执行图、Pipe 顺序、复用依赖和全局执行仍待官方准备检查**。即使这些成立，共享 DDR 竞争仍可能抵消预取收益，不能预告官方时延改进。

旧 `singleton_copy_bound` 的 37,194 下界仅覆盖原 singleton 计划，不能移到这个合桶候选；不会因此弱化旧守卫或废弃旧证据。作者 26,842 compute-only 数字仍是作者报告，本批没有重新计算，也不声称它可达。
