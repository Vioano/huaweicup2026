`regions()` groups *maximal weakly connected* eligible `PIPE_V` nodes using only edges whose two ends remain eligible. It limits total work but does not require DAG convexity. `_capsules()` then removes protected attention/FFN nodes, inserts each V region as one capsule, builds exclusive chains for leftovers, and topologically sorts the quotient. Original graph acyclicity does not imply quotient acyclicity: contraction of a nonconvex set can turn a path that leaves and reenters the set into a cycle. The explicit quotient check correctly rejects this case; the summary alone does not reveal which 071 nodes formed the cycle.

Minimal abstract counterexample: original DAG edges `v1 → v2`, `v1 → p`, `p → v2`, with `v1,v2` eligible V ops and `p` in a protected attention/FFN capsule. The V-induced weak component is `{v1,v2}`, yet its contraction gives `V → P → V`. The same failure arises when `p` is an exclusive chain. Work ≤ cross-core delay does not prevent it. The prior frontier audit found short cross-capsule paths but does not establish that any particular 071 region has this precise shape.

Safe deterministic rule: begin with protected capsules and singleton remaining ops; require that base quotient be acyclic. Process proposed V regions in fixed original topological/ID order. Tentatively merge a region and keep it **only if** a full quotient topological sort succeeds; otherwise leave its ops singleton. If exclusive chains are then desired, accept each chain merge under the same check. For `R` region and `C` chain proposals, rebuilding and sorting costs `O((R+C)(V+E))` time and `O(V+E)` working space. A simpler first correction is to reject the entire short-vector candidate on any quotient cycle and retain the already valid control route. Neither rule establishes a Makespan gain; legality and official E0 would still need separate evaluation of any later fixed candidate.
