**适用谓词。** 源码先要求旧 Task 数据 DAG 的各核顺序严格按高度前进、Task 数低于 320；同一高度的包互独立、每包唯一内部 sink、直接计算边与 COPY 收缩边一致，原 tensor 至多一生产者。每个目标波须有同 dominant Pipe 的超均值 donor 和低于均值的**已占用** helper；donor 包内须有双入边桥汇合，导出 X 前驱闭合、尾 J 后继闭合，X/Y/J 仅允许指向 J 的跨片边；整波搬运前的最大原始 Pipe 工作量必须下降，最终联合 Task DAG 无环。参见 `branch_aid.py:_wave_domain,_bridge_tree,_witness,construct`。本次核对旧 plan 高度、各波 Pipe 工作与“单 sink 包中双入边均为无向桥”的**必要形状**；未核桥树根方向、X/Y/J 闭包、单生产者等全部守卫，也未估新 COPY/FIFO/门控。

**筛掉的低优先级结构。** 068 的保存旧核顺序没有严格提高数据 Task 高度，触发首层拒绝；不能凭 `heavy-or-sink` 标签放行。069/071 虽各有 2 个双桥形状波，只有 4 个高度波，旧 M 分别 14,135/10,760；短工作与跨核门控风险高。064 的失衡波最大原始 Pipe 工作仅 88，远小于 1000-cycle 跨核 gate；048 波次多，但最大失衡 Pipe 工作仅 536。这些不是无优化余地或最优性证明，仅是不宜优先派 bridge-aid 评价的证据。

**均值空间只是必要上界。** 固定 `priority.json` 中 B/L 为合法下界导出的单格加速比上包络，绝非可达到的目标。上述五图的旧加速比至 B/L 空间分别为 005 **5.1183**、086 **4.9043**、047 **3.6732**、082 **3.1064**、075 **2.5774**；即使五格各自达到该理论包络，100 图 K5 均值最多增加 **0.193796**，仍低于当前 4.025907 均值再提升 5% 所需的 **0.201295**。四格 082/075/047/005 的对应包络和为 **0.144753**。这些界不能当作 R6 可恢复量。085/K5 的唯一真实 E0 从 783,703 到 681,874，额外 DDR 增 32.15%；它仅说明一个输入上的有效机制，且没有被计入上述旧 v4 五格空间。

**最小下一批建议（至多四格，须另行冻结与排程）。** 按结构多样性先取 **082/K5、075/K5、047/K5、005/K5**；085 已验证不重跑，086 暂留后续同类核对。每格先用现有输入与旧 plan 做完整适用守卫和新旧静态 COPY 账；只有固定候选确实生成且 Task/DAG/预算通过，才考虑原授权内一次独立官方 E0 对照。记录失败、额外 DDR、spill、完整 solver 墙钟与每波真实限制任务结束；005 若门控吞掉 X 的工作量应保留负结果。此建议不增加当前实验授权或全量预算。
