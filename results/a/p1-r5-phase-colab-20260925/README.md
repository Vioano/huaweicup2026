错相比本次同分区控制低 **15.6427%**，但比整链 A 多 **637 周期**，也未突破预声明门槛 **99264**。因此不建议追加 E0，不升级统一算法，不更新官方 Benchmark 均值。门槛是此前针对特定不切链类得到的条件下界，不是所有 P1 合法方案的下界；本试验失败也不证明错相构造普遍无效。

实际一次编译 **53 个 Task**，两次 Fraction 响应；E0/E1/E2、重试均为零。两计划的搬运总字节相同，均为 **3760344 B**；保存响应的 DDR 忙碌并集均为 **63084 周期**。这支持改进来自执行重叠与等待分布变化，不能把整个差值直接解释为消除了某一种 DDR 拥塞。

研究 runner 用时 **1.42266 s**，含识别、合法性检查、一次编译和两次响应；这是单个研究控制对的计时，不能代替生产统一算法的端到端耗时。控制窗口从 T0 到停机回读共 **36.87862 s**，包含云机创建、传输、依赖准备、运行和清理。stop 返回 0，随后 sessions 精确为空，远端剩余 runner PID 为空，本地 watchdog 已退出。没有继续第二台 VM 或评分。
