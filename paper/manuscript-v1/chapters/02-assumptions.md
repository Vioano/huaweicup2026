# 模型假设与符号说明

## 依据题面采用的条件

1. 原始图及官方配置保持不变。张量和操作 ID 在同一图内唯一，字节数及周期字段非负，原始依赖图无环；不删除计算、不改变操作数值语义。
2. 核心同构，每核 M、V、MTE2、MTE3 各有单槽执行资源。同核不同 Pipe 与不同核心可并发，但发射仍须满足依赖、Task 激活和存储申请条件。
3. 核内 L1 与 UB 容量分别为 524288 B 和 131072 B，两个存储池独立检查。所有 DDR 读写共享 60 B/cycle，问题三 Cache 容量为 1048576 B，命中读共享独立的 250 B/cycle 带宽池。
4. 问题一的同核 Task 切换等待为 100 cycles，跨核前驱 Task 等待为 1000 cycles；问题二、三跨核 COPY 同步等待为 500 cycles。具体等待作用于题面规定的完成与释放事件。
5. 官方核内调度、换入换出、存储申请顺序、整数周期及事件处理规则均属于执行语义。最终结果以原评价程序为准，不以理想并行模型替换。

以上是题目条件的建模化表达，不额外假设带宽无限、Cache 完美、计算与搬运必然完全重叠或所有任务耗时与环境无关。后文树排序、超图计费和候选下界所需的附加条件均在命题处单独给出；结构识别不通过时不使用相应结论。

## 对象层次与术语约定

为避免同一个“图”字承载不同约束，全文区分下列对象。

| 层次 | 对象 | 保留的信息 | 不能据此直接声称 |
|---|---|---|---|
| 输入层 | 原始二部图 | 操作、张量、大小、位置及原依赖 | 已经有执行次序 |
| 计算投影层 | 计算依赖 DAG | 保守保留的原计算因果 | 完整 COPY/MEM 关系 |
| 决策层 | 子图、分核及核序 | 参赛者能提交的两字段方案 | 直接控制操作发射时刻 |
| 结构层 | 增广子图 DAG | 数据依赖与全部核链 | 容量及动态执行成功 |
| 编译层 | Task 与扩展事件图 | COPY、spill、FIFO、存储申请规则 | 所有事件具有环境无关的时长 |
| 运行层 | 事件轨迹 | 发射、完成、驻留、共享服务与 Cache | 单一聚合分数足以恢复整个轨迹 |
| 观测层 | M、DDR、命中率及墙钟 | 各自明确定义的结果 | 不同指标可以相互替代 |

“子图”是方案中的划分对象；“Task”是评价器按场景构造的执行对象，二者只在问题一中一一对应。“原始张量”“编译后物理存储实例”和“Cache 查询使用的逻辑标识”分别按所在层解释，不能仅因显示名称相同就视作同一内存对象。

用 $\Theta=(G,q,K,C,H,R,I)$ 标记一次评价的语义身份：$C$ 为配置，$H$ 为官方源码身份，$R$ 为相关运行环境，$I$ 为入口、解析及调用契约。性能环境另记录硬件和并发。固定源码不能单独证明跨解释器或浮点运行时完全一致。

形式合法的输入集合、增广无环的结构方案集合和官方成功执行的方案集合分开记为 $\mathcal P_{\mathrm{in}}$、$\mathcal P_{\mathrm{ord}}$、$\mathcal P_{\mathrm{exec}}$。Makespan 只在成功结果上定义。官方拒绝、外部超时、取消、服务错误和未评价均保留各自状态；超时并不证明方案必然无效，也不填成零周期或无穷成绩参加均值。

本文的“精确”必须带对象：可以是某个费用公式精确、固定局部子问题精确、特定输入域的评分等价，或完整执行结果逐字段一致。四者不能省略限定后统一称为“精确求解”。类似地，“下界”必须说明约束全问题、受限方案族、一个固定方案还是某个理想模型。

后文出现 $d_v=\max(1,\mathrm{cycles}_v)$ 时，专指与官方计算投影一致的正整数执行时长；输入的原始字段仍允许为零。图中张量用圆角小框，操作用矩形，子图用带编号外框，核心用水平泳道。该约定用于区分“数据是什么”“计算做什么”“谁先谁后”和“放在哪个核心”四种信息。

## 指标定义与比较边界

对每个核数，平均加速比定义为

$$\bar S_{q,K}=\frac1{100}\sum_{i=1}^{100}\frac{B_i}{M_q(P_{i,K})}.$$

问题一、二的题目主曲线在 $K=1$ 处按单核基线定义为 1；算法输出的优化单核方案可以另报 $B_i/M_q(P_{i,1})$，不得把二者混写。由于 $B_i$ 是启发式基线而非单核最优值，加速比大于核心数不自动构成异常。

问题三的 Cache 比较使用同一个 $P_{i,K}$、图与配置，分别启用和关闭 L2。正文同时给出 $\operatorname{mean}(B/M_2)$、$\operatorname{mean}(B/M_3)$ 与 $\operatorname{mean}(M_2/M_3)$；前两条均值曲线之商通常不等于第三个量。

额外搬运量采用官方结果中的“调度后 COPY 字节数减去原始图 COPY 字节数”。问题三的该字段仍沿用官方 COPY 计费口径，不因命中而任意改计为零；因此不能把它直接称为 Cache 之后的实际物理 DDR 流量。Cache 命中率使用命中字节除以查询字节；跨用例给出的均值为逐图命中率的算术平均，不是把所有图字节拼接后得到的流量加权命中率。

求解墙钟包含输入读取、预处理、候选生成、在线评分、回退和方案落盘；在外部完成的最终官方复评单独报告。在线使用官方评价的时间已经属于求解墙钟，不能再次从中剔除。共享主机的并发批次墙钟、逐格进程时间和独占机器延迟是不同量，本文不相互替代。
