# 完整链与根核提前启动：Stage G 待证伪构造

Stage F 的实际 E0 为325520，比 Stage C 的253856退化。F固定分区必要DDR字节界259985已经超过C的完整Makespan，故仅调核顺序无法挽救该分区。此前模型R的166540结论仍只属于忽略搬运的放松模型。

本构造复用 `star_frontier.guarded_stages` 的结构守卫：每轮12条四操作等长PIPE_V链、11个二元归约节点，上一轮唯一根连接下一轮所有首节点；所有计算保留依赖与COPY收缩依赖必须一致。五核首轮按3/3/2/2/2整链分配，以后固定为4/2/2/2/2，归约尾一直放在核0。其他核数或不满足守卫时回退Stage C。没有case名称规则、候选枚举、在线评分、Task编译或历史成绩查表。

动机是上一轮根核可在100周期后启动，而其他核要等待1000周期。多给该核一条完整链也许能利用提前预取；官方DDR是所有活跃COPY公平共享总容量，不能按每次独占的串行FIFO分析。此效果是待检验假说。它可能因计算负载失衡反而恶化，不能由提前900周期推出必定获益。

每链内部没有新增Task边界。每轮五个前沿Task和一个尾Task，因此n轮有6n个Task。数据边及每核次序边均严格增加 `(stage, phase)`，联合图无环；原始操作恰出现一次。官方导出器进一步检查结构。该证明不替代E0的FIFO、COPY、内存处理或最终合法性。

对p=524、a=13、100/1000等待的051型模型R，首轮为 `12p+1000+11a=7431`，以后每轮为 `100+16p+100+11a=8727`，24轮共208152周期。这比Stage C的180644更大；模型R不足以选择DDR主导的构造。实际表现只由单独冻结的Stage G一次完整冷solver与一次未改E0确定。依赖旧C253856原件，不重跑基线。

构造阶段线性遍历节点和边；守卫沿用Stage C分解及堆/拓扑排序，整体保守上界 `O((V+E) log V)`，空间 `O(V+E)`。没有训练或预计算输入产物。单元检查仅使用合成小图、不同归约树和重编号，检查完整链/联合无环及手算R递推；不当作赛题成绩。
