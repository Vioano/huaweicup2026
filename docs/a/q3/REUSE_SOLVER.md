# 输入复用候选的受限在线接入

入口 `python -m src.q3.reuse_solve` 沿用 `safe_solve` 的输入、输出和证据格式。先完整运行 `forest_solve.evaluate_candidates`，保留该次求解的新鲜 incumbent；若三次 E0 总预算已经耗尽，直接返回。否则按实际张量读者集合识别完整二分网格，构造一份共享输入归核方案。仅比较两个轴遍历的解析输入覆盖代价，不扫描参数，不按算例编号分支。

候选与 incumbent 字节相同则跳过；已有合法 Pipe 下界不低于 incumbent 的官方 Makespan 则剪枝。剩余候选至多调用一次原版 E0，且只有官方 Makespan 严格降低才接受；平手或非法候选保留 incumbent。新增评价计入同一三次总调用限额及完整求解墙钟。无第四次兜底调用。

动机与局限见 [两图机制结果](../../../results/a/q3-nikolastarx/forest-reuse-grid-probe-20260925/REPORT.md)：058/5 的 M 降低 5.65%，079/5 则增加 2.30%，尽管两图输入复制下界和总额外搬运都下降。输入覆盖代价只能生成候选，不能代替官方选优。058 的 spill 增加，故较小 M 也不证明所有指标同时改善。

目前四项预算/接受规则回归测试和两图原计划字节精确重放通过。重放使用已有 E0 原件，不是新求解耗时或新统一算法全量成绩。独立覆盖检查先判断其实际适用范围及增量调用，随后再冻结有价值的正式运行范围；既有 forest500 固定源码和成绩保持其原身份。本文件不授权无界扩跑。

本入口的理论保证仅是：在上游调用计数正确、E0 结果可比的前提下，额外分支不使所选官方 Makespan 大于该次上游结果。对字节、命中率、程序墙钟、未见图或全局最优性没有此保证。
