# 单叶前瞻的固定机制对照

079依赖重建已确认最紧的某些等待来自**同树**ADD→MATMUL的L1复用边，不是原图计算依赖。目标是在不改变分核与M/V管线内部次序的前提下，调整跨管线提交顺序，减少这类等待。

1. **目标/输入**：原058/079、5核；每图固定原forest500与新band-pair两份owner/顺序控制，均为已见图。原件按 `bff88a66cd76ceb2d75242bf99d34bfe8b1879d4`、`27409658d869671d30e940f536bbab30d50d3ef9` 收据/字节核验，不把历史结果当作本次新求解。
2. **构造**：仅接受singleton、只有M/V计算且所有M无计算前驱的计划。原词 `M0,V0,M1,V1,...` 改为 `M0,M1,V0,M2,V1,...`，一次只让一叶领先；保留core归属、各pipe投影、原op/张量/子图ID，依赖合法性经官方静态derive核对。静态计算前沿至多多一个叶输出，不声称是包含共享输入及异步生命周期的容量证书。
3. **输出**：`leaf_lookahead.py`、受限回归检查；`leaf_lookahead_probe.py` 输出4新计划、调用账及完整原版E0结果。仅作为机制对照，非在线求解器或500格成绩。
4. **预算**：最多4新P3，每份只有严格优于该固定owner的旧P3时才补1次同plan P2，总计最多8次E0；1worker、单次90秒、整批360秒、0solver/0retry，首个失败即停。四计划都在第一次E0前保存；源码必须先提交。并行其他会话任务目录/进程不变。
5. **验收**：保持真实owner及M/V投影，核对SHA/原图/配置/官方身份；完整记录M、extra COPY、spill、字节命中率以及已测P2/P3。没有补测的P2为缺失，不算0；保留退化。构造墙钟和外部E0墙钟分列，不冒充端到端solver wall。
6. **决策**：只接受真实M收益证据；若有效，归纳适用结构与统一入口的成本再决定全量。若失效则检查真实内存边/重载变化，不继续扫描更多任意前瞻深度。本批不能证明全部已见图更优或未见图泛化，更不证明P3全局最优。

运行：`uv run --locked python -m src.q3.leaf_lookahead_probe results/a/q3-nikolastarx/leaf-lookahead-probe-20260925 --source FULL_COMMIT --forest-root FOREST_PRODUCER`。追加`--preflight`只构造和校验四份计划，不调E0。

静态顺序论证：M(i+1)无计算前驱，故前移跨过V(i)不会越过它的数据前驱；V相对次序和M相对次序都不变，V(i)也不可能依赖旧词中位于其后的M(i+1)。在每个交换区段，额外未消费的计算结果只有M(i+1)的输出，完成V(i)后与旧词执行到M(i+1)后的计算前沿一致。该上界只覆盖计算输出的静态活跃集合，不覆盖提前COPY、共享输入驻留或异步alloc/free，因此仍以官方验证为准。
