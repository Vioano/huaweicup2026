# 原始子树的单岛修复构造

本构造承接 Pro R3 的 AT.11：保持当前完整计算时序的外部区间不动，只释放一个 Attention 行或 FFN 块的区间；尝试将原 numerator 根的一个原始子树、或 FFN 的末端 MATMUL 移到另一个核。原算子、张量和归约树不变。每块仅比较一次原核重排和至多 `2(k−1)` 个结构明确的岛迁移，不做迭代随机搜索，也不调用 evaluator。

入口：`src.q3.island_repair.construct(Index(graph), singleton_plan, cross_delay)`。依赖相同的正整数 M/V、原始张量端口和无歧义 COPY 收缩守卫。纯 FFN 图也可使用；已有跨核块暂时跳过。未识别结构明确拒绝。输出仍只包含原提交的两个字段，诊断另行返回。

## 证书的确切范围

1. 从完整原方案的原依赖、每核每管线 FIFO、指定跨核延迟构造 ASAP 计算时序，并与既有独立 `pipe_bound` 核对。
2. 每个块释放自己的区间。持久 AVL 日历保留其他算子的全部区间，各候选只修改局部覆盖层。每个输入使用自己的 producer 完成时间，不把整个块的输入压成一个最大释放点。
3. 枚举每一个出口张量的全部外部消费者；针对其实际目标核比较到达时间。原图 COPY_OUT、没有消费者的张量和无输出节点也纳入终端约束。原核 control 必须不晚于当前完整 witness；岛候选又必须逐出口不晚于 control。不能只比较一个 sink 时刻或一个可能更差的 control。
4. 将新块区间与冻结外部区间拼接。候选块内部所有完成时间也不超过初始全局 horizon。于是每次更新保持一个可行、不增大的计算 witness。后续块仍根据更新后的实际端口与核重新检查。
5. 最终按 witness 的 `(start, original_op_id)` 生成全局顺序后投影至核，保留管线时序。重新用 `pipe_bound` 验证增强 DAG 的最长路不超过拼接 witness 和初始值。没有严格改善时返回原方案。

上述是计算松弛模型的可行性与不退化证书，**不是官方执行时间的上界，也不是官方不退化、内存可行性或全局最优证明**。原始输入在该松弛中从 0 可用；COPY 时长、共享 DDR/Cache、spill、内存补边均需最终 E0 判定。即使代理值下降，官方结果仍可能更差，接入求解器时必须保留合法 incumbent 和官方比较。

## 复杂度及未解决点

块不重叠，最多两个岛。局部试排扫描原块节点与输入边，单次区间查询/插入为对数时间；释放扫描对应区间及零长占位。候选只复制 `2k` 个日历根和块内的 owner/start/end，不复制全图。此部分约为 `O(k(N+E) log N + k²B)`，最终排序为 `O(N log N)`，其中 B 为块数。识别、官方结构校验和前后下界入口另计，不能把整个 Python 入口宣称为已证的纯线性过程。

冻结外部区间会排除有收益的共同迁移；仅两个根子树也会漏掉更深层切分。逐出口不退化比全局 Makespan 不退化更严格。这些是后续可以有依据放宽的约束，不应靠盲目增加迭代次数绕开。

## 验证

独立增强 DAG 计时器检查 3 个 FFN、短任务跨核不划算、多个外部计算/写回出口、Attention 不同通信延迟和 30 个固定随机种子的合成 FFN 计划。典型合成例：3 个 FFN、2 核、头尾 M 各2000、两段 V 各10、跨核延迟500；原核头优先顺序为8000，迁移第二块的末端 M 后为6520。这是机制例，不能计入正式 case 成绩。

`tests/q3/test_gap_calendar_release.py` 另以随机位图 oracle 检查释放/合并、旧根不变、双释放拒绝与 AVL 不变量。
