# 输入副本数的联合覆盖下界

范围：完整二分网格 K(m,n)，每个边是一棵不可拆的原计算树。第i核负责e_i条不同边，其重输入组和轻输入组支持大小记r_i、s_i；每组字节分别为a、b。这里只界定逻辑输入副本字节 D=sum_i(a*r_i+b*s_i)，不界定物理DDR流量、spill、L2命中或Makespan。

独立支持约束 `r_i*s_i >= e_i` 忽略了各核能否共同覆盖全网格。下面两个联合必要条件进一步收紧它：

```
sum_i r_i * (1 + [s_i = n]) >= 2m
sum_i s_i * (1 + [r_i = m]) >= 2n
```

证明：固定一行。若它出现在至少两个核的支持中，第一式左侧的该行贡献至少2；若只出现在一个核，该核必须含全部n列才能覆盖这一行的所有边，因此满列指示量使贡献也是2。逐行求和得到第一式；逐列同理。零边核的支持为(0,0)，不改变结论。这是必要而非充分条件：满列支持也未保证该核真的接收某一行的全部边。

`reuse_projection_bound.lower_bound` 枚举每核合法支持大小，动态规划累计两项贡献并分别截断于2m、2n，最小化副本字节。截断保留可行性，因为未来贡献非负且约束仅要求下限。标量DP的时间上界 O(k*m²*n²)、空间 O(m*n)；当前Python版本在每状态保存长度至多k的支持见证，因此实现上界为时间 O(k²*m²*n²)、空间 O(k*m*n)，这里k≤5。这是对实际边划分的松弛，所以最优DP值仍是合法下界；输出的支持见证不代表真实划分可实现。

058/5（17×15，a=270336、b=135168，每核51条边）的旧独立下界14,192,640 B升至 **14,733,312 B**；079/5（18×16，a=202752、b=135168，58/58/58/57/57条边）从12,840,960 B升至 **13,246,464 B**。现有轴遍历方案分别为15,814,656 B和15,273,984 B，仍不能据此宣称最优。证明只适用于规定的均衡整树边计数，拆树、不均衡分核或其他可提交方案未被此证书覆盖。

验证：独立枚举小网格的全部边染色（含空核及全部负载向量）验证DP值不超过真实最优；另复算两张原图的已识别参数。该检查0次E0，不是性能实验。本结论独立推导于等待Pro第四轮期间，未把网页生成进度当作已完成证明。
