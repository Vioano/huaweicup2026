# Shared-input stationary wave (experimental P2 constructor)

`src/q2_nikolastarx/shared_stationary_wave.py` exposes `build(graph, cores, config)` and `build_from_index(index, cores, config)`. Both return a singleton-subgraph plan and diagnostics. It is an isolated constructor; no production router selects it automatically. No E0/E1/E2 calls or official scoring occur during construction.

Applicability is exactly `shared_input_wave._recognize`: at least two independent, structurally identical compute components; at least two external tensors shared by every component; one unambiguous consumer anchor per shared tensor and component; tensor incidences reproduce contracted precedence; no multi-producer outputs or direct op edges. Unsupported graphs raise `UnsupportedStructure`. The strategy has no case-ID branch.

For each shared tensor in anchor topological order, the constructor takes the predecessor closure of its anchor in **every** job. An operation enters the first closure that reaches it; remaining operations form a residual stage. Within each stage, operations are appended in predecessor-first order. Thus each eligible operation occurs once, and concatenating the stages gives one common topological order. Each full stage has one core owner, so all consumers of a shared external tensor load it on one core. Consecutive stages are assigned to up to the requested number of cores. A deterministic dynamic program minimizes the largest normalized per-pipe compute work across contiguous partitions, with the earlier cut winning ties. It partitions stage work only and never evaluates or selects among generated plans.

The emitted schedule is the common stage-major order projected onto each core. `derive_multicore_plan` checks structural legality, and the constructor checks coverage and shared-input owner count. Diagnostics include stage/core per-pipe work and estimated transfer bytes: external input once per consuming core, intermediate tensor crossings as one output plus one input per distinct destination core, and terminal output bytes. These bytes exclude spill copies. The `capacity` shape is validated but does not prove zero spill; official Step2/Step3 can reorder priorities, add spill and copy contention, and change makespan. The estimate is not a bound or official score.

Validation: `uv run --locked python -m unittest tests.test_q2_shared_stationary_wave -v` exercises a synthetic repeated-input fixture, legal coverage/topology, input ownership, ID-renaming invariance, and heterogeneous-template rejection. This does not establish benefit on an official graph or case044.
