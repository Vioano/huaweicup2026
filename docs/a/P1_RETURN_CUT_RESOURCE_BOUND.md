# 返程切口构造类：先核对资源下界，再扩大搜索

2026-09-25。根代理推导；Sol 独立核对代数和限定语义。实现见 `src/review/p1_return_cut_resource_bound.py`。这是不运行编译器、响应模拟或评分器的元数据分析，用来判断研究空间，尚未接入生产剪枝。

## 适用范围与计时模型

考虑同型、私人 `M(a) -> V*(b) -> M(c)` 链，`b` 是整段 V 的正整数工作量。每条链始终属于一个核；核 k 固定含 N_k 条。每条链只能完整 W 留在一个 Task，或在最后一个 M 前切成 P、R 两个 Task 片段。不同链可以组合进同一 Task。要求无 spill、保持官方的计算顺序，并满足每条未切 W 的两个 M 在其 Task 的 M FIFO 中相邻。

官方 Step1 从 sink 反向 DFS，私人分量之间没有边。完整 spine 的终点（或它的边界 COPY_OUT）比同分量的中间 COPY_OUT 更深；终点自身若是 sink 则具有非 COPY_OUT 优先级。首次进入该分量时会完成整条 compute spine，期间不访问其他分量。Step2 无 spill 时保持 compute 序；Step3 从该序过滤出 Pipe FIFO，新增 MEM 前驱不改变 FIFO。故上述相邻性可由这些限定前提导出；任意非私人图、其他内部切口、跨核拆链不在本论证内。

这里的 T 是**精确共享 DDR 服务、完整 FIFO 依赖**模型中的周期时间；每个 COPY 的独占工作量逐项取 `max(1, ceil(size / bandwidth))`。尚未证明官方 E0 的 binary64/EPS 事件舍入在所有输入上绝不低于此界，不能直接以本结果剪掉官方候选、声称官方最优或全 P1 最优。题目实际成绩仍由冻结 E0 产生。

## 从构造降到一个小资源问题

设核 k 有 x_k 条切开的链，0 <= x_k <= N_k。未切 W 的两个 M 之间至少经历其自身 b 个 V 周期，并且其他 M 不能插入这一 FIFO 间隙。各完整链的 M 间隙与其他链的 M 工作互不重叠，所以：

`T >= N_k(a+b+c) - b*x_k`，且 `T >= N_k*b`。

设 d_P、d_R、d_W 为相应片段的全部边界 COPY 独占服务。按官方边界谓词包含旁路输入、死输出及显式 COPY_OUT；不能只数主干切口。令 `Delta=d_P+d_R-d_W >= 0`，`C=sum(N_k)*d_W`，则共享 DDR 有：

`T >= C + Delta*sum(x_k)`。

舍去容量、MEM 等待、Task 门控及其他时序约束，只会使这个问题更乐观。资源问题的可行解不是合法方案，不应把它给出的 x_k 当作已验证构造比例。

## 连续闭式解与整数强化

写 A=a+b+c。给定 T，连续切链数至少为 `max(0,(N_k*A-T)/b)`，还须 T >= max(N_k)*(a+c)。DDR 条件中的正部和等于对所有子集取最大；给定子集大小 m，最大的 N_k 构成最强条件。因此连续资源最优值精确等于以下各项的最大值：

- `max(N_k)*b`；
- `max(N_k)*(a+c)`；
- 对 m=0..K，`[b*C + Delta*A*sum(largest m N_k)] / [b + Delta*m]`。

原构造的 x_k 必须为整数。给定整数 T，必要的最小切链数为 `x_k(T)=max(0,ceil((N_k*A-T)/b))`。当且仅当每项不超过 N_k、V 工作不超过 T 且 `C+Delta*sum(x_k(T)) <= T`，整数资源问题可行。这个谓词随 T 单调，故在 `[max(max(N_k)*b,max(N_k)*(a+c),C), max(max(N_k)*A,C)]` 内二分求最小可行整数。

这是小资源放松问题的精确解，不是对实际调度进行暴力迭代。时间 `O(K log K + K log U)`、额外空间 `O(K)`；读取和识别原图的成本另计。最小 T 可行、T-1 不可行是资源问题的证据，不能替代完整调度证明。

## 对当前研发的作用

纯元数据首轮计算（008、084、095，K=5）分别得到整数资源值 76020、335819、322992；后续可复现结果将附固定脚本 SHA 与输入 SHA。这些值没有排除进一步改进，仍需更紧的 FIFO/门控下界或真正更优构造。084 数值与旧 Pro 报告吻合，是一次独立资源计算，不是重新运行其调度实验。
