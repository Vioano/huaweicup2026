# 理论界补充适用条件：原 tensor 的唯一生产者

在与本机P2会话去重理论工作时，对方指出其实现还限制每个原tensor至多一个producer。根会话随后重读冻结官方Step2的backing选择、incarnation重命名和消费边重接。我们原来的IO路径与区间工作量证明没有独立处理同一原tensor多producer、跨核COPY及复用DDR backing的组合。因此收紧程序的证明域：**每个原tensor至多一个原producer（包括原COPY），有多producer时拒绝给出这一组界**；不根据“已有结果未超过T”扩张结论。

这是保守收紧，不宣称已构造出多producer下的官方反例，也不宣称此前实际500格数值已被证伪。原依赖不收缩COPY桥的规则、IO的no logical_tid守卫、逐pipe区间工作量不等式及阈值优化证明不变。零字节COPY仍按官方最少1周期；重读官方发现共享DDR池确实以_op_duration作为工作量，不能擅自把它换成未取整的bytes/bandwidth。

head_tail_bound.py与lower_bounds.py增加相同拒绝守卫，合成测试分别检查多producer拒绝及唯一producer的既有数值。没有修改任何旧原件、线上solver、计划或E0结果。新源只收紧入口，对通过守卫的图运算不变；不重跑100图阈值计算或500次E0。
